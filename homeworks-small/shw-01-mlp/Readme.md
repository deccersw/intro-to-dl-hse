# Отчет об использовании ИИ
**Используемая модель**: gpt6 Astra с режимом effort - light. 

**Среда выполнения**: Расширение codex для  - vscode

**Основные сценарии использования ИИ**:
1. **Рефакторинг кода** - с ним модель умело справляется. С точки зрения рефакторинга - находит все допущенные ошибки. В частности умело справляется с необходимостью транспонирования и reashapа матриц, что в силу человеческого фактора можно забыть.
2. **Построение графиков** Модель использовалась для написания кода для построения графиков, в частности графика завимости ошибок на train  и val в зависимости от разных порогов lr и weight_decay.

**Замеченные проблемы при использовании ИИ:**
- Модель не сразу понимает, что используем собственную имплементацию pytorch. По этому при рефакторинг предлагает заменить собственные методы на торчовые. Смею предположить, что при повышение effortа, а также написания более четкого промпта, данной проблемы можно избежать.
